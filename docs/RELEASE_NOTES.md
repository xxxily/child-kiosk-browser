## Child Kiosk Browser v0.0.6

本版本修复了上个版本在预缓存和交互中的体验 Bug，提升了预加载性能稳定性和网页区域的正常点击交互。

> **说明**：本 APK 使用 debug 签名，仅供调试与家庭内部部署。生产/商用请自行用正式 keystore 重新签名。

### 本版本核心变化

* **修复预缓存/预加载 100% 页面卡死 Bug**：
  - 解决了由于 `AndroidView` 实例 attach 时重新触发 `onPageStarted` 却因网页已完全载完不再触发 `onPageFinished` 导致的 Loading 遮罩层无法正常消失的重入问题。我们在 `onPageStarted` 中拦截过滤了 progress == 100% 的通知。
  - 使用 `remember(preloadEntry)` 对参数 and 加载进度状态进行同步，解决了 1 帧延迟的状态滞留问题。
  - 修复了挂载时误将已加载成功的实例底色重置为暖黄色 `#FFF8E1` 的问题，自适应识别并保障渲染底色。
* **去除网页右上角的隐藏点击区域，恢复完全交互**：
  - 移除了在 `WebViewActivity` 中悬浮在网页右上角的 80dp 盲点击透明框。解决了该透明框拦截网页对应坐标元素（如设置、菜单等右上角按钮）点击事件的问题，网页现在获得了百分之百的正常触控。
  - 去除了盲触退出机制。用户可通过物理/虚拟返回键或者长按手势轻松退回至主屏幕，再由主屏幕锁头统一进入后台，界面逻辑更纯粹安全。

## Child Kiosk Browser v0.0.5

本版本重点解决了 WebView 网页浏览时的**白屏、冷启动耗时、SPA 单页应用过渡闪烁**等体验问题。引入了**网页后台预加载与复用池**、**系统空闲时的 WebView 引擎预热**、**7天自动缓存自动回收与一键清理**，并重新设计了**全屏加载遮罩、平滑过渡动画和友好的网页错误拦截页**。为儿童上网和网页游戏提供无缝、流畅、“秒开”的视觉体验。

> **说明**：本 APK 使用 debug 签名，仅供调试与家庭内部部署。生产/商用请自行用正式 keystore 重新签名。

### 本版本核心变化

* **后台预加载与秒开复用池 (Phase 4)**：
  * 家长可在控制台开启「网页后台预加载」选项（默认开启）。
  * 开启后，主页在完全闲置（通过主线程空闲 `IdleHandler` 触发）时，会自动在后台通过协程分步预加载排名前 3 的常用站点。
  * 当儿童点击卡片时，直接从预加载池中取出已缓存/已渲染完毕的 WebView 挂载使用，实现瞬间打开的秒开体验。
  * **OOM 与内存防线**：集成了 Application 的 `onTrimMemory` 监听，在系统内存低/极低时自动裁减或清空预加载池以保障系统整体稳定。
* **自定义进程架构简化**：
  * 移除了 `WebViewActivity` 的独立 `:webview` 子进程。由于 Android 系统限制，非同进程的 View 实例无法直接跨进程共享或 addView 挂载，为了实现 WebView 后台预加载的跨 UI 挂载，重构并合并回了主进程。
* **Chromium 引擎冷启动预热 (Phase 2)**：
  * 在 Application 初始化时自动在主线程空闲期预创建一个轻量 WebView 实例，触发 Chromium 引擎的初始化，彻底消除了用户首次打开应用网页时引擎冷启动的数百毫秒耗时。
* **暖色底色与白屏消除**：
  * 将 `WebViewActivity` 的 Activity 窗口背景、Compose 布局底色、以及 `WebView` 实例初始画布底色统一设置为应用暖黄色 `#FFF8E1`，网页完全载入后再自动恢复白色，完美消除了白屏闪烁，并避免了无背景网页文字无法识别的问题。
* **全屏网页加载遮罩层与三重就绪判定 (Phase 1)**：
  * 在网页加载未就绪时显示全屏加载遮罩，展示专属图标（自动解析网络 favicon 或矢量图）、圆形进度条和儿童友好提示文案。
  * **三重就绪判定**：结合网页进度 >= 85%、`onPageFinished` 触发以及 `evaluateJavascript` 注入 JS 检查 DOM 实质子节点渲染状态，完美解决了传统方案中 SPA 单页应用因为“空壳 HTML”瞬间关闭遮罩暴露白屏的痛点。
  * **最少展示时间限制**：预载遮罩最少展示 600ms，配合 400ms 的淡出过渡动画，提供精致平稳的过渡效果。
* **友好网页错误与异常拦截提示**：
  * 当网页加载遇到主框架加载失败、超时、SSL证书异常或服务器返回 HTTP 4xx/5xx 时，加载遮罩会平滑切为精美的报错提示页，并提供「重试一下」与「返回乐园」按钮，代替原始丑陋的系统崩溃白屏或无反应卡死。
* **双重缓存策略与定时垃圾清理 (Phase 3)**：
  * 尊重 HTTP 头缓存，且启动时会自动检查距离上次清理是否超过 7 天，是则自动在后台进行缓存清理。
  * 家长管理后台新增「立即清理」卡片，一键清除网页缓存与 Cookie，省心好用。

## Child Kiosk Browser v0.0.4

本版本支持**删除预设白名单应用**、**内置图标库扩增（12个）**、**自定义 Favicon 卡片排版美化与实时预览**，并新增了**退出网站验证开关**、**主页右上角家长控制锁头图标显示/隐藏选项**以及**主页标题文本自定义与隐藏选项**，进一步提升了家长控制的自由度与用户界面的美观性。

> **说明**：本 APK 使用 debug 签名，仅供调试与家庭内部部署。生产/商用请自行用正式 keystore 重新签名。

### 本版本核心变化

* **白名单应用完全自由删除**：
  * 去除了默认预设应用（如腾讯视频、爱奇艺等）的删除限制，家长在后台控制台可自由删除任意默认白名单应用，彻底避免了应用“锁死”无法清理的问题。
* **内置图标库扩增**：
  * 内置图标从 5 个扩增至 12 个，包含：星星、书本、手柄、视频、音乐、地球、相机、学校、灯泡、笑脸、心形、主页，为不同类别的网站应用提供更丰富的视觉选项。
* **自定义 Favicon 卡片排版优化与实时预览**：
  * 重构了自定义图标输入卡片的布局，由横向单行重构为纵向两行设计。
  * 引入了 56dp x 56dp 的 Coil `AsyncImage` 框进行实时图片预览。当输入有效的 HTTP/HTTPS 图片网址时，自动加载展示预览，加载失败或格式不合法时优雅显示警告，界面高档雅致。
* **网站退出验证按需配置（默认无需验证）**：
  * 新增“退出网站时需要验证”开关（默认关闭）。
  * 关闭时，按返回键或在顶部盲区连续点击 5 次可直接退回主页，极大地简化了用户的常规使用；开启后则与以往一致，需通过家长密码验证才能退出，满足了安全退出的个性化需求。
* **可交互管理锁图标与隐藏配置**：
  * 默认在主页面右上角提供一个精致的“锁头”图标引导首次使用的用户，点击该锁头多次即可直接弹出验证框，降低了家长后台的认知与寻找门槛。
  * 在后台控制台提供“隐藏右上角管理锁图标”开关，开启隐藏后，锁头图标不显示，依然保留通过在右上角无图盲点击 5 次触发密码验证的隐藏机制。
* **主页标题文字自定义与隐藏**：
  * 提供了自定义主页标题文本配置，可将默认的“我的游戏乐园”修改为任意个性化名称。
  * 提供了“隐藏主页标题文字”开关，允许隐藏该文本，留出更多屏幕空间给应用网格。

## Child Kiosk Browser v0.0.3

引入**自定义网址图标与 Favicon 自动推导**，支持**屏幕显示方向设置**以及**首屏网格图标大小缩放**，并完美解决横屏下 Dialog 遮挡与状态栏灰色半透明块卡死的体验瑕疵。

> **说明**：本 APK 使用 debug 签名，仅供调试与家庭内部部署。生产/商用请自行用正式 keystore 重新签名。

### 本版本核心变化

* **网络自定义图标与 Favicon 自动推导**：
  * 引入 `Coil` 异步图片加载库，支持网络图标缓存与优雅的加载失败（显示 Star 图标）容错。
  * 添加应用时自动根据输入的 URL 提取协议、主机及端口，并自动拼接推导为默认的 `/favicon.ico` 地址。
  * 提供内置图标与自定义 URL 输入框的勾选单选卡片，可任意选择及修改，默认优先填充推导的 Favicon。
* **屏幕显示方向配置**：
  * 支持三种显示方向：自适应（AUTO）、锁定横屏（LANDSCAPE）、锁定竖屏（PORTRAIT）。
  * 移去了 Manifest 中的硬编码方向锁，在 `onCreate` 最早期以 Preference 同步设置，完美解决了 Activity 启动瞬间闪屏和多进程 WebView 的方向一致性。
* **首屏图标显示大小**：
  * 支持三种图标显示大小：小（SMALL，网格 `90.dp`）、中（MEDIUM，网格 `120.dp`）、大（LARGE，网格 `160.dp`）。
  * 适合横屏模式下排布更多的应用，极佳地适应不同设备屏幕比例。
* **系统栏自动重置沉浸**：
  * 引入系统 insets 监听器，在儿童下拉呼出状态栏（出现半透明灰条）后，**自动在 3 秒后重新收回隐藏系统栏**，彻底杜绝状态栏在部分 OEM 设备上卡死占位。
* **局域网与测试 HTTP 放行**：
  * 网络配置文件与 Android 清单全面放行明文 HTTP 协议流量，并为家长添加 HTTP 应用时增加醒目的橙色风险告知。
* **Dialog 横屏滚动支持**：
  * 添加应用 Dialog 加入了滚动条（Column `verticalScroll`），解决了横屏下按钮被阻挡且无法交互的重大体验瑕疵。

## Child Kiosk Browser v0.0.2

引入**分级防护模型**：不再强制恢复出厂 + Device Owner。普通侧载安装即可开箱使用，应用按当前可用权限自动选择最高防护等级。

> **说明**：本 APK 使用 debug 签名，仅供调试与家庭内部部署。生产/商用请自行用正式 keystore 重新签名。

### 本版本核心变化

| 档位 | 防护等级 | 激活条件 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **Tier 1** | 企业级完全锁定（Device Owner） | 恢复出厂 + ADB 激活 | 长期专用平板，绝对防逃逸 |
| **Tier 2** | 屏幕固定软锁（**默认**） | 普通安装即可 | 家长普通侧载，日常防误触 + 基础防逃逸 |
| **Tier 3** | 无系统级锁定 | 普通安装 + 后台切换 | 开发调试、临时体验、配置网站 |

- 主网格**不再以 Device Owner 为使用前提**：装上即可用，无需 ADB；
- 家长后台新增「**防护等级**」卡片，可在 Tier 2 / Tier 3 间切换，并内置 Device Owner 升级引导；
- 沙箱安全能力（HTTPS 强制、同源白名单、广告/下载拦截、SSL 严格校验、独立进程）、家长验证、时长限制**三档完全一致**，分级只影响系统级锁定强度。

### 安装与部署

#### 路径 A：普通侧载（推荐给大多数家长 / 开发者）

无需恢复出厂、无需 ADB：

1. 下载下方 Assets 中的 `child-kiosk-browser-0.0.2-release.apk`；
2. 直接安装并打开，默认进入 **Tier 2 屏幕固定软锁**，主网格立即可用；
3. （可选）家长后台 → 防护等级卡片 →「设为默认主屏幕」，重启后自动回到本应用；
4. （可选）家长后台添加网站白名单、设置时长与 PIN 码。

> 想纯净体验或调试？家长后台把防护等级切到 **Tier 3** 即可随时用 Home 键进出。

#### 路径 B：Device Owner 完全锁定（要求绝对防逃逸时）

1. 平板**恢复出厂设置**，跳过 WiFi 与账号绑定；
2. 开启开发者选项与 USB 调试；
3. `adb install child-kiosk-browser-0.0.2-release.apk`；
4. 激活 Device Owner：
   ```bash
   adb shell dpm set-device-owner com.example.childkiosk/.MyDeviceAdminReceiver
   ```
   返回 `Active admin set` 即成功；
5. 家长后台防护等级卡片 →「设为默认主屏幕」选择本应用；
6. 重启平板，开机自动进入 Tier 1 完全锁定的儿童沙箱。

### 家长操作手册

- **进入家长后台**：屏幕**右上角** 80dp 区域 2 秒内连续点击 5 次 → 通过验证 → "进入系统白名单及时间配置后台"
- **切换防护等级**：管理后台顶部「防护等级」卡片
- **退出锁定**：管理后台底部 "退出并安全解锁（返回系统桌面）"
- **修改密码 / 切换验证方式**：管理后台 → 家长身份验证配置
- **设置时长**：管理后台 → 儿童健康使用时长限制（拖动 Slider）
- **添加新网站**：管理后台 → 右下角 + 按钮（仅支持 https，自动连通性检测）

### 已知限制

- APK 使用 debug 签名，仅适用于个人测试 / 家庭部署
- Tier 2 屏幕固定可被系统手势（长按 返回+最近任务）解除，防护强度低于 Tier 1，这是 Android 普通应用的固有限制
- Tier 2 首次激活时部分 OEM 会弹一次系统「是否固定此应用」确认框，属预期行为
- Tier 1 的 Device Owner 一旦激活无法通过卸载解除，必须 `adb shell dpm remove-active-admin` 或恢复出厂设置
- 部分国产 ROM 对 Device Owner 兼容性不一致，建议使用接近原生 Android 的设备（Pixel、AOSP 平板、Lenovo M 系列等）
